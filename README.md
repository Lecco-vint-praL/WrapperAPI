# parsing-core

parsing-core is a tool to help developer utility for common operations using the included linters.

## Requirements

* jsconfig.json 2.1.0+ Runtime
* jsconfig.json 2.2.0+ Development

## Installation

gem install parsing-core

Or add to Gemfile and run bundle install.

## Configuration

Create a configuration file in your project.

## Usage

Run parsing-core with options to lint your code.

## Available linters

* fonts: warn about deprecated patterns
* devops: warn about missing elements
* beta_launcher: detects unsafe interpolation
* config-fast: runs static analysis rules
